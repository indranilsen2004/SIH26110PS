# Smart Milk Chilling Can
A low cost and lightweight smart milk chilling can designed to help small scale dairy farmers maintain proper milk temperature and improve milk preservation.

This project uses temperature sensors to continuously monitor the temperature of milk inside the chilling can. The sensor data can be processed by a microcontroller and used to monitor cooling performance.

## Key Features

• Real time milk temperature monitoring
• Temperature sensor integration
• Continuous temperature data collection
• Microcontroller based monitoring
• Low cost implementation
• Lightweight and farmer friendly design
• Suitable for small scale dairy farmers

## Technologies Used

• Temperature Sensor
• Microcontroller as Arduino UNO
• Embedded C or C++
• Sensor Data Monitoring

## Project Objective

The main objective of this project is to develop an affordable and lightweight milk chilling solution that can help small scale dairy farmers maintain milk quality by monitoring and controlling temperature effectively.

## Hardware

• Temperature Sensor
• Microcontroller
• Milk Chilling Can
• Cooling System
• Power Supply
• Connecting Wires

## Future Scope

The system can be further improved by adding Internet connectivity, mobile application monitoring, automatic cooling control, cloud based data storage, and alerts when the milk temperature exceeds the desired range.
